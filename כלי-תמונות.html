🖼️ כלי תמונות למנהל

הופך תמונה מהמחשב לקוד שמדביקים בעמודת image בשיטס — בלי אתר חיצוני.

📁 לחץ לבחירת תמונה / גרור לכאן / הדבק (Ctrl+V)

בוואטסאפ ווב: קליק ימני על התמונה → ״העתק תמונה״ → כאן Ctrl+V ✨
(קישור blob: לא עובד באתר — חייבים את התמונה עצמה)

איך משתמשים:
1️⃣ בחר תמונה (קובץ / גרירה / הדבקה)
2️⃣ לחץ ״העתק לשיטס״
3️⃣ בשיטס, בעמודת image של הקבוצה → הדבק (Ctrl+V)
4️⃣ רענן את האתר — התמונה מופיעה! 🎉
→ חזרה לאתר
